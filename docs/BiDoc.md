## نظرة عامة | Overview

**متقن** هو منصة SaaS متكاملة لإدارة الصيانة والمرافق، مصممة لتلبية احتياجات المؤسسات المختلفة مع **مرونة كاملة في التخصيص**.

### المبادئ الأساسية:
- ✅ كل موديول قابل للتفعيل/التعطيل والتخصيص لكل مؤسسة
- ✅ لا يوجد شيء مفروض على الجميع - كل مؤسسة حسب حاجتها
- ✅ تخصيصات داخل كل موديول يتحكم فيها صاحب الصلاحية
- ✅ فصل كامل بين المؤسسات وعزل آمن للبيانات

## الأدوار والصلاحيات - مستويين

### المستوى الأول: إدارة المنصة (Platform Level)

لوحة تحكم خاصة لإدارة النظام والمنشآت

| الدور | الكود | الوصف |
|-------|-------|-------|
| مالك المنصة | `platform_owner` | صلاحيات كاملة على كل شيء |
| مدير النظام | `platform_admin` | إدارة المؤسسات والإعدادات |
| الدعم الفني | `platform_support` | مساعدة المؤسسات وحل المشاكل |
| المالية | `platform_finance` | الفواتير والمدفوعات |
| الموارد البشرية | `platform_hr` | إدارة موظفي المنصة |

#### ميزات إدارة المنصة:
- إمكانية إضافة أدوار جديدة
- تعديل صلاحيات كل دور
- إضافة صلاحيات استثنائية لمستخدم معين
- وصول معين للوحة تحكم المؤسسات (كل واحدة على حدة)
- إمكانية تحديد صلاحية الموظف لمؤسسة دون الأخرى
- صلاحيات مختلفة داخل المؤسسات (قراءة/كتابة/تعديل)
- **سجل عمليات تفصيلي** لمتابعة موظفي المنصة

---

### المستوى الثاني: إدارة المؤسسة (Tenant Level)

لوحة تحكم خاصة بكل مؤسسة معزولة بشكل آمن

| الدور | الكود | الوصف |
|-------|-------|-------|
| مدير النظام | `tenant_admin` | صلاحيات كاملة داخل المؤسسة |
| مدير المرافق | `facility_manager` | إدارة المرافق والفرق |
| مدير الصيانة | `maintenance_manager` | إدارة أوامر العمل والموافقة النهائية |
| مهندس | `engineer` | مراجعة واعتماد |
| مشرف | `supervisor` | الإشراف على الفنيين |
| فني | `technician` | تنفيذ أوامر العمل |
| مُبلِّغ | `reporter` | رفع البلاغات فقط (صلاحيات محدودة جداً) |

#### ميزات إدارة المؤسسة:
- تخصيص واسع للأدوار
- إضافة وتعديل الصلاحيات
- فصل تام بين المؤسسات

## الموديولات والتخصيص

> **مبدأ أساسي:** كل موديول قابل للتفعيل/التعطيل والتخصيص لكل مؤسسة

### 1. 📊 الرئيسية (Dashboard)
**داشبورد مخصص** - كل مؤسسة تختار ما يُعرض:
- المؤشرات والعدادات
- الروابط السريعة
- الرسوم البيانية المطلوبة

---

### 2. 🏢 المنشآت (Facilities)
- المباني على شكل بطاقات مع بيانات بسيطة
- زر إضافة مبنى
- **هيكل اختياري:**
  - مبنى ← أدوار ← أقسام ← غرف
  - كلها اختيارية حسب الحاجة

---

### 3. 📦 الأصول (Assets)
**عرض شجري جميل:**
```
├── مبنى أ
│   ├── أصول المبنى
│   ├── الدور ب
│   │   ├── أصول الدور
│   │   └── القسم ج
│   │       └── الغرفة د
│   │           └── أصول الغرفة
```

**الميزات:**
- إجراءات على الأصول (صيانة، إطفاء، تشغيل روتيني، إلخ)
- إجراءات على المباني
- فلترة متقدمة
- تصدير البيانات
- توليد QR لكل أصل (اختياري)
- كل الإضافات قابلة للتخصيص

---

### 4. 📋 أوامر العمل (Work Orders)

#### صفحة البلاغات:
- بلاغات معزولة لكل مؤسسة
- **معلومات البلاغ:**
  - اسم المُبلِّغ
  - الوقت والترميز بالتاريخ
  - اختيار الأصل بالترتيب (مبنى ← دور ← قسم ← غرفة)
  - الوصف
  - صورة (اختيارية)
  - نوع الصيانة
  - تعيين الفريق تلقائياً حسب التخصص (مع إمكانية التغيير)

#### سير العمل (Workflow):
```
البلاغ يُرسل → الفريق المعين
    ↓
الفني (قبول/رفض + ملاحظة)
    ↓ [اختيار قطعة غيار من المخزون - اختياري]
المشرف (موافقة/رفض + ملاحظة)
    ↓
المهندس (اعتماد/رفض)
    ↓
المُبلِّغ (موافقة/رفض) - 24 ساعة ثم اعتماد تلقائي
    ↓
مدير الصيانة/المشروع (الاعتماد النهائي)
```

#### التخصيص:
- حد أدنى وأقصى للمراحل
- تخصيص الأشخاص والاعتمادات
- سجل إجراءات بالوقت والتاريخ
- **تصدير PDF:**
  - شعار المؤسسة
  - شعار شركة الصيانة/التشغيل
  - شكل مستند قابل للتخصيص
  - تفاصيل كاملة قابلة للتخصيص

## نظام الاشتراكات

### الباقات المخصصة:
- تسعير الموديول الأساسي (Standard)
- تسعير الموديول مع كل تخصيص
- إمكانية تضمين التخصيصات ضمن الاشتراك لمؤسسة معينة
- المؤسسة ترى باقتها فقط

### آلية التسعير:
```
الموديول الأساسي: X ريال
+ التخصيص أ: Y ريال
+ التخصيص ب: Z ريال
= الإجمالي
```

أو يمكن تضمين التخصيصات ضمن الباقة

## قاعدة البيانات الكاملة

### إجمالي الجداول: 37 جدول

---

### 1. نظام الاشتراكات والمستأجرين (6 جداول)

#### 1.1 tenants
**الوصف:** المستأجرون (المستشفيات/المنظمات) مع إدارة الاشتراكات الكاملة

**الأعمدة الرئيسية:**
- `id` - UUID Primary Key
- `name`, `slug` - الاسم والمعرف الفريد
- `subscription_status` - حالة الاشتراك (trial/active/suspended/cancelled/expired)
- `plan_id` → subscription_plans - الخطة الحالية
- `subscription_starts_at`, `subscription_ends_at` - فترة الاشتراك
- `trial_ends_at` - انتهاء الفترة التجريبية
- `billing_cycle` - دورة الفوترة (monthly/yearly/custom)
- `payment_method` - طريقة الدفع
- `max_users`, `max_assets`, `max_work_orders_per_month`, `max_storage_mb` - الحدود
- `enabled_modules` - الوحدات المفعلة
- `primary_color`, `secondary_color` - ألوان العلامة التجارية

---

#### 1.2 subscription_plans
**الوصف:** خطط الاشتراك المتاحة

**الأعمدة:**
- `code`, `name`, `name_ar` - المعرف والاسم
- `price_monthly`, `price_yearly` - الأسعار
- `is_featured` - خطة مميزة؟
- `included_users`, `included_assets`, `included_storage_mb`, `included_work_orders` - الموارد المتضمنة
- `features` - JSONB قائمة الميزات

**البيانات الموجودة:** 4 خطط (Free Trial, Starter, Professional, Enterprise)

---

#### 1.3 subscription_history
**الوصف:** سجل تغييرات الاشتراكات

#### 1.4 invoices
**الوصف:** الفواتير

#### 1.5 payments
**الوصف:** المدفوعات

#### 1.6 tenant_modules
**الوصف:** تفعيل الوحدات لكل مستأجر
