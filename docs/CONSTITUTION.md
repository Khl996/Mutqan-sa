## 🎯 نظرة عامة

**متقن** هو منصة SaaS متكاملة لإدارة الصيانة والمرافق، مصممة لتلبية احتياجات المؤسسات المختلفة مع مرونة كاملة في التخصيص.

## 👥 نظام الأدوار - مستويين

### المستوى الأول: إدارة المنصة
| الدور | الكود | الوصف |
|-------|-------|-------|
| مالك المنصة | `platform_owner` | صلاحيات كاملة |
| مدير النظام | `platform_admin` | إدارة المؤسسات |
| الدعم الفني | `platform_support` | مساعدة المؤسسات |
| المالية | `platform_finance` | الفواتير والمدفوعات |

### المستوى الثاني: إدارة المؤسسة
| الدور | الكود | الوصف |
|-------|-------|-------|
| مدير النظام | `tenant_admin` | صلاحيات كاملة داخل المؤسسة |
| مدير المرافق | `facility_manager` | إدارة المرافق والفرق |
| مدير الصيانة | `maintenance_manager` | إدارة أوامر العمل |
| مهندس | `engineer` | مراجعة واعتماد |
| مشرف | `supervisor` | الإشراف على الفنيين |
| فني | `technician` | تنفيذ أوامر العمل |
| مُبلِّغ | `reporter` | رفع البلاغات فقط |

## 📦 الموديولات

> **مبدأ أساسي:** كل موديول قابل للتفعيل/التعطيل والتخصيص لكل مؤسسة

1. **📊 الرئيسية** - داشبورد مخصص
2. **🏢 المنشآت** - مباني ← أدوار ← أقسام ← غرف
3. **📦 الأصول** - عرض شجري + QR + إجراءات
4. **📋 أوامر العمل** - سير عمل متعدد المراحل
5. **📜 سجل العمليات** - تتبع جميع الأحداث
6. **⏱️ SLA** - اتفاقيات مستوى الخدمة
7. **📜 العقود** - إدارة العقود
8. **💰 التكاليف** - تتبع التكاليف
9. **👥 الفرق** - إدارة فرق العمل
10. **🔧 الصيانة** - دورية + وقائية + Kanban
11. **📦 المخزون** - قطع الغيار
12. **📊 التقارير** - تلقائية + تحريرية

## 💳 نظام الاشتراكات

- تسعير مخصص لكل موديول (يمكن أن يكون صفر)
- تسعير التخصيصات داخل كل موديول
- المؤسسة ترى باقتها فقط
- عزل كامل بين المؤسسات
