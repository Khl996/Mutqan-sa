## 1. السياق

المؤسس يعمل كمهندس ميكانيكا في شركة تشغيل وصيانة متعاقدة مع مستشفى صحة نفسية، وبدأ تجربة ضيقة وغير رسمية لمتقن داخل بيئة العمل.

هذه التجربة ليست عميل تجاري رسمي، وليست مادة تسويقية عامة، لكنها إشارة تشغيلية مهمة لأنها تختبر متقن في بيئة صيانة حقيقية.

## 2. قواعد الخصوصية

أي قراءة من قاعدة البيانات يجب أن تكون:

- قراءة فقط.
- بدون أسماء موظفين.
- بدون بريد إلكتروني أو أرقام جوال.
- بدون بيانات مرضى أو تفاصيل حساسة.
- على شكل أرقام وأنماط عامة فقط.

يوجد تضخم واضح في الإشعارات بتاريخ 2026-04-25:

- بعض أوامر العمل أنتجت أكثر من 50 إشعارا.

هذا مؤشر يستحق فحصا قبل تفعيل واتساب أو أي قناة خارجية، لأن أي تضخم داخلي سيتحول إلى إزعاج مباشر للمستخدمين إذا أرسلناه واتساب.

## 6. حالة البريد الحالي

النظام الحالي:

إشعار داخلي -> Trigger في قاعدة البيانات -> `pg_net` -> Edge Function `resend-email` -> Resend.

الملاحظة المهمة:

- Edge Function `resend-email` فعالة.
- إعدادها الحالي في Supabase يظهر `verify_jwt = true`.
- استدعاءات قاعدة البيانات عبر `pg_net` لا ترسل Authorization JWT.
- آخر ردود `net._http_response` بتاريخ 2026-04-30 كانت `401`.

الاستنتاج:

قناة البريد الحالية غالبا لا تعمل بشكل صحيح في آخر اختبار، أو على الأقل توجد مشكلة تفويض بين قاعدة البيانات و Edge Function.

تحديث القرار:

البريد الإلكتروني هو القناة الرسمية المعتمدة حاليا، لكن يحتاج إصلاح إعداد `resend-email` قبل اعتباره فعالا.

## 7. قرارات مطلوبة

قبل إضافة واتساب:

1. إصلاح أو تعطيل قناة البريد الحالية حتى لا يبقى لدينا تريغر خارجي يفشل بصمت.
2. تقليل تضخم الإشعارات الداخلية، خصوصا عند أوامر العمل التي تنتج عشرات الإشعارات.
3. إضافة تفضيلات قناة الإشعار لكل مستخدم: داخل النظام، بريد، واتساب لاحقا، Push لاحقا.
4. عدم إرسال أي بيانات حساسة في الإشعار الخارجي. الرسالة تكون مختصرة وتوجه المستخدم لفتح متقن.

## 8. توصية تنفيذية

لا نربط واتساب مباشرة على كل إشعار الآن.

الترتيب الصحيح:

1. تنظيف منطق الإشعارات الداخلية.
2. إصلاح قناة البريد أو إيقافها مؤقتا.
3. إضافة طبقة `notification_deliveries` لتتبع حالة كل قناة.
4. تجربة واتساب كقناة اختيارية على مستخدمين داخليين فقط.
5. لاحقا، عند وجود تطبيق جوال أصلي، تصبح Push Notifications هي القناة الأساسية، ويبقى واتساب للقنوات العملية أو العملاء الذين يفضلونه.
