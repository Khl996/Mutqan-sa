## 1. ملخص القرار التنفيذي

التركيز لهذا الأسبوع هو الانتقال من جاهزية الديمو إلى بداية البيع الفعلي، مع تجهيز نسخة عميل من عرض Pilot المدفوع.

| القرار | جواب المؤسس | التفسير التنفيذي |
| --- | --- | --- |
| نطاق أول Pilot | خلك سخي في النطاق | نعطي العميل قيمة واضحة، لكن مع حدود مكتوبة تمنع النطاق المفتوح. |

| خطة الأسبوع | إضافة brand والبوابة العامة وآراء الإدارات | تدخل ضمن خطة الأسبوع القادم ومراجعة الإدارات. |

## 3. سياسة النطاق السخي

السخاء المطلوب لا يعني فتح كل شيء. الصياغة التنفيذية:

نقدم Pilot غني بما يكفي ليشعر العميل بقيمة حقيقية، لكن داخل حدود تشغيلية واضحة.

النطاق السخي المقترح لأول Pilot مناسب:

| البند | الحد السخي المقترح |
| --- | --- |
| المواقع | حتى 3 مواقع ضمن Pilot واحد إذا كانت البيانات والمسؤوليات واضحة |
| المستخدمون | حتى 25 مستخدما نشطا إذا كانت الأدوار واضحة |
| الأصول | حتى 250 أصل إذا كانت البيانات جاهزة أو شبه جاهزة |
| أوامر العمل | تشغيل أوامر عمل حقيقية خلال فترة Pilot |
| الأدوار | مدير/مسؤول، مشرف أو مهندس، فني، ومقدم بلاغ عند الحاجة |
| التقارير | تقرير أسبوعي وتقرير نهاية Pilot |
| التدريب | جلسات مختصرة للفئات الأساسية، وليس تدريب كل موظفي المنشأة |

الخط الأحمر:

- لا تكاملات ERP/BMS/IoT.
- لا واتساب رسمي.
- لا تطبيق جوال أصلي.
- لا دعم 24/7.
- لا تشغيل عدة مواقع معقدة بلا مالك واضح أو بيانات جاهزة.
- لا تنظيف بيانات ضخم.
- لا تقارير مفتوحة بلا حدود.
- لا تخصيصات كود كبيرة ضمن السعر الأساسي.

## 4. قرار المدة

المدة التنفيذية الآمنة:

| نوع Pilot | المدة | متى يستخدم؟ |
| --- | ---: | --- |
| Pilot محدود | 6 أسابيع | بيانات جاهزة، نطاق صغير، مستخدمون قليلون |
| Pilot سخي ومنضبط | 8 أسابيع | حتى 3 مواقع أو حتى 25 مستخدما أو حتى 250 أصل أو متابعة أسبوعية أعمق |
| نطاق أكبر | 8 أسابيع أو أكثر مع سعر أعلى | إذا زادت المواقع أو البيانات أو التعقيد |

قرار العمل:

لأول عميل مدفوع، نعرض 8 أسابيع كنطاق افتراضي إذا اخترنا أن نكون سخيين في النطاق. 6 أسابيع تبقى خيارا فقط إذا كان النطاق صغيرا والبيانات جاهزة.

## 4.1 ملاحظة السعر مقابل شهرين

سؤال المؤسس: هل 15,000 ريال كثيرة على شهرين؟

التقدير التنفيذي:

15,000 ريال ليست كثيرة إذا كان Pilot يشمل إعداد وتشغيل وتدريب ومتابعة أسبوعية وتقرير نهاية تجربة. هذا ليس اشتراكا برمجيا فقط، بل خدمة تنفيذ مصغرة لإثبات القيمة.

لكن حتى لا يشعر العميل أن السعر مرتفع، نربط السعر بالنطاق:

| النطاق | السعر الآمن |
| --- | ---: |
| Pilot صغير جدا، موقع واحد، بيانات جاهزة، 4 إلى 6 أسابيع | 12,000 إلى 15,000 ريال كعرض دخول خاص |
| Pilot سخي ومنضبط، حتى 3 مواقع، حتى 25 مستخدما، حتى 250 أصل، 8 أسابيع | 15,000 إلى 25,000 ريال |
| Pilot أوسع أو بيانات أصعب أو متابعة أكثر | 25,000 إلى 40,000 ريال |

قاعدة البيع:

لا نقدم أقل من 15,000 ريال كعرض قياسي. إذا نزلنا إلى 12,000 ريال، يكون ذلك فقط كعرض إطلاق مشروط بحدود أضيق أو مرجع تجاري أو سرعة قرار.

## 6. قائمة الإيقاف لهذا الأسبوع

- لا نبيع اشتراك سنوي قبل Pilot ناجح أو دليل قيمة.
- لا نعد بواتساب رسمي.
- لا نعد بتطبيق جوال أصلي.
- لا نفتح تكاملات.
- لا نوسع المنتج قبل أول مسار بيع حقيقي.
- لا نرسل عرض Pilot يحتوي بدائل دفع كثيرة أو أقسام داخلية.
- لا ننقل CRM إلى أداة ثقيلة قبل وضوح الحاجة، إلا إذا كان ربط HubSpot جاهزا ولا يبطئ البيع.
