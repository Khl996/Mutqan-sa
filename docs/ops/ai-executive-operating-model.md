# نموذج التشغيل التنفيذي بالذكاء الاصطناعي في متقن

الحالة: مسودة حوكمة حية  
المالك: المؤسس  
المشغل التنفيذي: Codex  
آخر تحديث: 2026-05-01

## 1. الغرض

تحدد هذه الوثيقة كيف تعمل متقن كشركة يقودها المؤسس وتدعمها إدارات متخصصة بالذكاء الاصطناعي.

نموذج التشغيل هو:

المؤسس كمالك -> Codex كمشغل تنفيذي -> الإدارات المتخصصة كوحدات تحليل وتنفيذ داخل نطاقها.

الهدف ليس خلق بيروقراطية. الهدف هو فصل التفكير، حوكمة القرارات، تتبع التنفيذ، وتسهيل التوظيف مستقبلا.

## 2. الأدوار

### المؤسس / المالك

المؤسس يملك:

- رؤية الشركة.
- القرار النهائي.
- قرارات الصرف.
- التزامات العملاء.
- قرارات التوظيف.
- المفاضلات الاستراتيجية.
- قبول المخاطر.

لا يجب أن يحمل المؤسس كل التفاصيل التشغيلية في ذاكرته. القرارات يجب أن توثق وتتحول إلى عمل.

### Codex / المشغل التنفيذي

Codex يعمل كمشغل تنفيذي.

مسؤولياته:

- تحويل توجيه المؤسس إلى خطط تشغيلية، وثائق، مهام، تغييرات منتج، وأنظمة متابعة.
- تنسيق مدخلات الإدارات المتخصصة.
- إبقاء كل إدارة داخل نطاقها.
- كشف التعارضات بين الإدارات.
- تصعيد القرارات التي تحتاج موافقة المؤسس.
- تحويل القرارات المعتمدة إلى عمل في Notion أو Linear أو GitHub حسب الأداة المناسبة.
- حفظ الدليل: ملفات، تغييرات، تحقق، ملاحظات، وخطوات تالية.

Codex لا يملك الحكم التجاري النهائي. يوصي وينفذ ضمن توجيه المؤسس أو ضمن حدود معتمدة مسبقا.

### الإدارات الوكيلة

الإدارات الوكيلة هي وحدات تخصصية.

يجب أن:

- تبقى داخل مجالها.
- تستخدم الميثاق والوثائق المصدرية.
- تنتج مخرجات منظمة.
- لا تقدم التزامات عابرة للشركة.
- تصعد القرارات العابرة للمجالات إلى Codex والمؤسس.

لا يجب أن:

- تغير استراتيجية إدارة أخرى.
- تقدم وعودا للعملاء.
- تعدل التزامات إنتاجية أو عميل بدون موافقة.
- تخترع حقائق بلا دليل.
- تحول كل فكرة إلى خارطة طريق.

## 4. خط الأساس لقدرات الذكاء الاصطناعي

تستطيع أنظمة الذكاء الاصطناعي الحالية دعم متقن بخمسة أشكال عملية:

1. أعمال المعرفة: تلخيص الدراسات، استخراج القرارات، كتابة الإجراءات، مقارنة الخيارات، وتجهيز المذكرات.
2. استخدام الأدوات: قراءة الملفات، تحديث الوثائق، فحص الكود، تشغيل التحقق، والاتصال بالأنظمة.
3. المخرجات المنظمة: إنشاء سجلات، قوائم تحقق، قوالب، حقول CRM، ومعايير تقييم قابلة للتكرار.
4. سير عمل وكيل: تقسيم العمل بين وكلاء متخصصين مع تسليمات وأدوات وحواجز حماية.
5. حلقات تقييم: قياس هل الموجهات وسير العمل والوكالات تنتج مخرجات صحيحة ومفيدة.

أفضل ممارسة لمتقن:

نبدأ بإدارات وكيلة تحت إشراف بشري وقوائم تحقق منظمة. نضيف الأتمتة بعد ثبات سير العمل. نضيف الاستقلالية فقط عندما يمكن فحص المخرجات وتقييمها.

## 5. أفضل ممارسات الذكاء الاصطناعي لمتقن

### استخدم الوكلاء للتخصص، لا للاستعراض

نستخدم إدارة وكيلة عندما يحسن التخصص جودة القرار.

استخدامات جيدة:

- إدارة المنتج تراجع ملاءمة خارطة الطريق.
- إدارة الأمن تراجع مخاطر الصلاحيات أو الثقة.
- إدارة المبيعات تؤهل عميل محتمل.
- إدارة نجاح العملاء تجهز خطة تهيئة.
- إدارة المالية تراجع خطر الخصم.

استخدامات غير مناسبة:

- خمس إدارات تناقش تصحيحا لغويا بسيطا.
- وكلاء ينتجون استراتيجية بدون سجل قرار.
- وكلاء ينتجون مهاما بلا مالك أو موعد.

### سير العمل قبل الاستقلالية

أغلب عمل متقن يجب أن يبدأ كسير عمل:

مدخل -> قائمة تحقق -> مخرج -> مراجعة -> قرار -> مهمة.

الوكلاء الأكثر استقلالية يأتون لاحقا بعد نجاح السير نفسه عدة مرات تحت إشراف.

### المخرجات يجب أن تكون منظمة

كل إدارة وكيلة يجب أن ترجع:

- ملخصا.
- أدلة أو افتراضات.
- توصية.
- مخاطر.
- إجراء مطلوب من المؤسس.
- مهام تنفيذ.
- تصعيدات.

### حواجز الحماية

كل إدارة تلتزم بهذه الحواجز:

- لا تعد بميزات غير متاحة.
- لا تبالغ في جاهزية المنتج.
- لا تغير التزامات العملاء بصمت.
- لا تستخدم بيانات عميل حقيقية في عرض أو مادة عامة بدون موافقة.
- لا تتجاوز بوابات الأمن.
- لا تدخل الذكاء الاصطناعي أو IoT أو BMS أو BIM أو تطبيقات الجوال الأصلية في نطاق التجربة الحالي.

### التقييم للمهام المتكررة

ننشئ قوائم تقييم صغيرة للأعمال المتكررة:

- دقة تأهيل المبيعات.
- اتساق نطاق العرض.
- مراجعة عدم كسر الوعود التسويقية.
- اكتمال المراجعة الأمنية.
- جودة قائمة جاهزية العرض.
- جودة خطة تهيئة العميل.

## 6. الإيقاع التشغيلي

### فحص يومي بين المؤسس والتنفيذي

المدة: 10 دقائق.

الأسئلة:

- ماذا تحرك أمس؟
- ما العائق؟
- أي قرار يحتاج موافقة المالك؟
- ما إجراء الإيراد أو العميل اليوم؟

### مراجعة تنفيذية أسبوعية

المدة: 45 إلى 60 دقيقة.

نراجع:

- خط المبيعات.
- التجارب أو الفرص النشطة.
- عوائق المنتج.
- مخاطر نجاح العملاء.
- بوابات الثقة والأمن.
- قرارات النقد والصرف والأدوات.
- القرارات المنتظرة لموافقة المؤسس.

الناتج:

- تحديث سجل القرارات.
- تحديث الأولويات.
- مهام الأسبوع.
- إجراءات العملاء التالية.

### مراجعة استراتيجية شهرية

المدة: 90 دقيقة.

نراجع:

- ماذا علمنا السوق؟
- أي افتراض في الدراسة كان خاطئا؟
- أي مواثيق إدارات تحتاج تحديث؟
- أي أتمتات أصبحت جاهزة؟
- ماذا يجب أن نوقف؟

الناتج:

- تحديث نظام الشركة.
- تحديث قرار القطاع المستهدف.
- تحديث خارطة 30 يوما.

## 7. سير القرار

كل قرار مهم يمر بهذا المسار:

1. الإدارة ترفع توصية.
2. Codex يفحص التعارضات والأدلة.
3. المؤسس يعتمد أو يرفض أو يطلب تعديل.
4. القرار يسجل.
5. مهام التنفيذ تنشأ.
6. النتيجة تراجع في تاريخ محدد.

حقول سجل القرار:

| الحقل | المعنى |
| --- | --- |
| القرار | ماذا قررنا. |
| التاريخ | متى صدر. |
| المالك | من يملك النتيجة. |
| النوع | منتج / مبيعات / عميل / مالية / أمن / توظيف / أدوات. |
| السبب | لماذا اتخذ القرار. |
| الدليل | ما الذي دعمه. |
| البدائل | ماذا درسنا. |
| المخاطر | ماذا قد يحدث. |
| تاريخ المراجعة | متى نعيد النظر. |
| المهام المرتبطة | روابط Notion أو Linear أو GitHub. |

## 9. مبدأ الأتمتة

لا نؤتمت إلا بعد وضوح العملية.

الترتيب الصحيح:

يدوي -> قائمة تحقق -> قالب -> شبه أتمتة -> أتمتة كاملة.

ما نؤتمته:

- تذكيرات المتابعة.
- قوالب تسجيل القرار.
- فحوص جاهزية العرض.
- مسودات العروض من نطاق معتمد.
- قوائم انطلاق التجربة.
- تقارير قيمة التجربة الأسبوعية.
- توجيه الملاحظات.

ما لا نؤتمته الآن:

- اعتماد التسعير النهائي.
- الخصومات.
- التزامات العملاء.
- قبول المخاطر الأمنية.
- تغيير الاستراتيجية.
- التوظيف.

## 10. قواعد التصعيد

يصعد الأمر للمؤسس عندما:

- يطلب العميل شيئا خارج نطاق التجربة.
- تؤثر التوصية على السعر أو الوعد أو الخطر أو خارطة الطريق.
- تضيف الأداة تكلفة شهرية.
- يمس تغيير المنتج الأمن أو الفوترة أو عزل المستأجرين أو بيانات العملاء.
- تختلف إدارتان على الأولوية.
- ستؤخر مهمة حركة البيع أكثر من أسبوع.

## 11. أول خطوة تنفيذية

أول تنفيذ ليس منصة ذكاء اصطناعي معقدة.

نبدأ بـ:

1. مواثيق الإدارات.
2. سجل القرار.
3. خط المبيعات.
4. المراجعة التنفيذية الأسبوعية.
5. موجهات وقوائم تحقق للإدارات الوكيلة.
6. قائمة أتمتة مؤجلة.

بعد أسبوعين إلى أربعة أسابيع من الاستخدام المتكرر، نحول سير العمل الثابت إلى أتمتات متصلة.
