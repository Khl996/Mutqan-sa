- تزوير الدليل: PATCH مباشر إلى `pdf_snapshot` رُفض بـHTTP `403`.
- الحوكمة: السجل النهائي `approved` وقرار الاعتماد مختوم بممثل فعلي.
- إثبات الإنجاز: `pdf_snapshot` موجود و`contract_version = 2`.
- قصة الأصل: كُتبت `9` سجلات تشغيل للرحلة بواسطة `5` ممثلين مختلفين؛ أصبح للأصل `18` سجلًا مرتبطًا بعد الرحلتين المقبولتين.
- الهوية النهائية للأدوار تطابق السجل: المبلّغ الأصلي، الفني المكلّف، المشرف، المهندس، ثم المبلّغ نفسه للإغلاق.

## 4. العيوب التي كشفها القبول وإغلاقها في المصدر

1. لم تكن الواجهة تعرض مسار `evaluate_work_order_approval` ثم `approve_governance_decision`، مع أن قاعدة البيانات تمنع البدء قبله. أضيف مسار حوكمة صريح وfail-closed قبل زر Start.
2. كانت قائمة الإسناد تعرض `maintenance_manager` رغم أن SQL يقبل `technician` أو `engineer` فقط. قُيدت القائمة بالأدوار المطابقة للقاعدة والمستخدمين النشطين.
3. كان يمكن للواجهة إظهار Start لفني على أمر `pending` غير مسند، بينما SQL يرفضه. أصبحت الواجهة تخفي الإجراء حتى يكون الفني هو المكلّف المباشر.
4. كانت ملفات `supabase/.temp` متتبعة في Git، وكان المرجع السابق يحتوي project ref للإنتاج. أضيف المسار إلى `.gitignore` وأزيلت ملفات الحالة المؤقتة من Git index مع إبقائها محليًا للمشغل.
5. كان دليل Canary لا يذكر حساب `engineer` ضمن قائمة الحسابات رغم طلب رحلته. صُححت القائمة.
6. كانت التواريخ والأزمنة النسبية تبقى عربية عند تبديل الواجهة إلى الإنجليزية، وبعض الحالات تعرض مفاتيح ترجمة خامًا. أصبحت الصياغة تتبع لغة الواجهة، وأضيف عرض صريح وآمن لكل حالات أمر العمل.
7. كان اعتماد المهندس ينجح في قاعدة البيانات لكن الواجهة قد تبقى على الحالة القديمة لحظيًا. أصبحت إعادة جلب حالة أمر العمل وسجل النشاط جزءًا منتظرًا من نجاح الإجراء.
8. كان الإغلاق من الواجهة يرسل ملاحظة آلية لا تعبّر عن إدخال المستخدم. أصبحت الملاحظة فارغة ما لم يكتب المستخدم محتوى فعليًا؛ يبقى النص السابق في سجل الاختبار القديم فقط كأثر تاريخي للقبول قبل الإصلاح.
9. كشف الاختبار أن RLS يخفي ملف المستخدم غير النشط تمامًا، لذلك قد تعود قراءة الملف `null` بدل `is_active = false`. أصبحت بوابة Auth fail-closed: لا تُقبل الجلسة إلا عند وجود ملف صريح بقيمة `is_active = true`، وتُزال الجلسة المحلية عند الغياب أو عدم التفعيل.
