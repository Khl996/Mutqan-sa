# عرض تجربة متقن التشغيلية المدفوعة

الحالة: مسودة بيع جاهزة للمراجعة  
المالك: المؤسس  
آخر تحديث: 2026-05-01

## 1. اسم العرض

تجربة متقن التشغيلية المدفوعة

## 2. وصف مختصر

متقن يساعد فرق المرافق والصيانة على تحويل العمل المتفرق إلى سجل تشغيلي مترابط يشمل البلاغات، المواقع، الأصول، الفنيين، إثبات الإنجاز، التقارير، والقرارات الإدارية.

## 3. العميل المناسب

أفضل العملاء الأوائل:

- شركات إدارة مرافق تدير موقعا أو أكثر.
- مجمعات سكنية أو تجارية لديها فرق صيانة نشطة.
- مشغلو صيانة لعدة مواقع.
- عيادات، مدارس، مستودعات، مصانع، أو مكاتب لديها مسؤول صيانة واضح.

الحد الأدنى للملاءمة:

- بيئة تشغيل حقيقية.
- راع أو صاحب قرار واضح.
- مالك تجربة يومي.
- موقع أو مجموعة أصول أو فريق محدد للتجربة.
- استعداد لاستخدام متقن في عمل حقيقي أثناء التجربة.

## 4. مدة التجربة

المدة المقترحة: 8 أسابيع.

يمكن تمديدها إلى 12 أسبوعا إذا كان الإعداد أكثر تعقيدا.

| المرحلة | المدة | الناتج |
| --- | ---: | --- |
| التأهيل | أسبوع | تأكيد الملاءمة، النطاق، الراعي، مالك التجربة، ومعايير النجاح. |
| الإعداد | أسبوع إلى أسبوعين | إعداد الحساب، المستخدمين، المواقع، الأصول المختارة، وسير العمل. |
| التمكين | أسبوع | تدريب مستخدمي التجربة وتأكيد أول سير عمل. |
| التشغيل الحي | 4 إلى 6 أسابيع | تشغيل أوامر عمل حقيقية، وصيانة وقائية ومخزون إذا كانا ضمن النطاق. |
| المراجعة | أسبوع | تقديم تقرير قيمة التجربة وتوصية الاشتراك السنوي. |

## 5. النطاق المشمول

التجربة تشمل إعدادا تشغيليا محددا، لا تحولا مفتوحا.

| المجال | المشمول |
| --- | --- |
| إعداد المنظمة | حساب عميل واحد، إعدادات أساسية، أدوار ومستخدمون محددون. |
| المواقع | موقع واحد أو هيكل مواقع محدود. |
| الأصول | قائمة أصول مختارة ببيانات أساسية وربط بالموقع. |
| أوامر العمل | إنشاء، تعيين، تحديث، إكمال، مراجعة، وإغلاق. |
| الصيانة الوقائية | جداول محدودة وقوائم فحص عند الحاجة. |
| إثبات الإنجاز | ملاحظات، طوابع زمنية، حركة حالة، وأدلة إنجاز متاحة. |
| المخزون | رؤية أساسية لقطع الغيار إذا وفر العميل بيانات أولية. |
| التقارير | لوحة تشغيلية وإشارات مراجعة إدارية. |
| التدريب | تهيئة يقودها المؤسس للمستخدمين المتفق عليهم. |
| المراجعة | تقرير قيمة التجربة وتوصية التحويل. |

حدود التجربة المقترحة:

- منظمة عميل واحدة.
- موقع أو فريق أو مجموعة أصول محددة.
- من 20 إلى 100 أصل مختار.
- من 5 إلى 20 مستخدما.
- من 3 إلى 10 جداول صيانة وقائية إذا شملت التجربة PM.
- 20 أمر عمل حقيقي أو أكثر خلال فترة التشغيل.

## 6. المستبعد صراحة

هذه العناصر ليست ضمن التجربة إلا إذا تم تسعيرها واعتمادها بشكل مستقل:

- ربط أجهزة IoT.
- تكامل BMS.
- تكامل أو عارض BIM.
- مساعد ذكاء اصطناعي، روبوت محادثة، ذكاء تنبؤي، أو توصيات آلية.
- تطبيق iOS أو Android أصلي.
- عمل دون اتصال كامل.
- تكاملات عميقة مع ERP أو المالية أو HR أو المشتريات أو CAFM أو CMMS أو SSO أو التحكم بالوصول.
- تغييرات قاعدة بيانات مخصصة لعميل.
- نسخة كود مخصصة لكل عميل.
- ترحيل وتنظيف تاريخ كامل.
- دعم 24/7 أو مسؤولية طوارئ ميدانية.
- تطبيق امتثال تنظيمي كامل.
- تخصيص غير محدود.

صياغة آمنة:

متقن مبني ليدعم مستقبلا طريقا نحو التكاملات والذكاء التشغيلي، لكن هذه التجربة المدفوعة تركز على الأساس التشغيلي الذي يجعل تلك القدرات المستقبلية قابلة للتصديق.

## 7. التسعير

حالة التسعير:

الأرقام أدناه توصية داخلية غير معتمدة رسميا. لا يتم إرسالها أو عرضها كعرض نهائي قبل موافقة المؤسس.

نطاق إطلاق مقترح:

| نوع التجربة | مناسب لـ | السعر المقترح |
| --- | --- | ---: |
| تجربة قياسية | موقع واحد أو مجموعة أصول محددة | 25,000 ريال |
| تجربة متقدمة | إعداد أكثر، مستخدمون أكثر، PM مع مخزون | 40,000 ريال |
| تجربة استراتيجية | منظمة أعقد مع تقارير تنفيذية وإعداد أعمق | 60,000 ريال فأكثر |

شروط دفع مقترحة:

- 50% عند بدء الإعداد.
- 50% قبل التشغيل الحي.

خصم شريك إطلاق:

- يسمح فقط لعميل مرجعي استراتيجي.
- لا يجب أن يحول التجربة إلى مجانية.
- أي خصم يجب أن يرتبط بتغذية راجعة، تصريح شهادة، أو قيمة مرجعية.

## 8. مسار التحويل السنوي

التجربة مصممة للتحول إلى اشتراك سنوي.

نطاق سنوي مقترح وغير معتمد حتى الآن:

| الفئة | مناسبة لـ | النطاق السنوي المقترح |
| --- | --- | ---: |
| أساس التشغيل | موقع أو فريق واحد مع سير العمل الأساسي | 60,000 إلى 90,000 ريال |
| تشغيل مترابط | عدة مواقع أو PM ومخزون وتقارير أعمق | 100,000 إلى 180,000 ريال |
| ذكاء تشغيلي | حساب أكبر مع تقارير ومراجعات وتوسع | 200,000 ريال فأكثر |

الإعداد والتدريب وتنظيف البيانات والتكاملات تسعر كخدمات مهنية مستقلة عند الحاجة.

## 9. معايير النجاح

تنجح التجربة عندما يوجد دليل تشغيلي، لا مجرد تسجيل دخول.

إشارات النجاح الدنيا:

- اكتمال أوامر عمل حقيقية داخل متقن.
- ربط المواقع والأصول المختارة بحركة العمل.
- تحديث الفنيين أو المستخدمين لحالة العمل والملاحظات.
- قدرة الإدارة على مراجعة المفتوح والمتأخر والمكتمل والوقائي.
- تحديد العميل لثلاثة قرارات تشغيلية على الأقل تحسنت ببيانات متقن.
- اتفاق العميل على نطاق سنوي تال أو تقديم أسباب واضحة لعدم الاستمرار.

## 10. مسؤوليات العميل

على العميل توفير:

- راع تنفيذي أو صاحب قرار.
- مالك تجربة للتنسيق اليومي.
- قائمة مستخدمين وأدوار.
- مواقع وأصول أولية.
- جداول PM أولية إذا شملها النطاق.
- التزام بتسجيل سير العمل المتفق عليه في متقن أثناء التجربة.
- تغذية راجعة وحضور مراجعات.

## 11. مسؤوليات متقن

متقن يوفر:

- مراجعة الملاءمة وتأكيد النطاق.
- إعداد الحساب والتكوين الأساسي.
- إعداد بيانات موجه باستخدام قوالب متفق عليها.
- تهيئة المستخدمين.
- دعم التجربة داخل الحدود المتفق عليها.
- تقرير قيمة التجربة.
- توصية الاشتراك السنوي.

## 12. إغلاق البيع

صياغة مقترحة:

إذا كان هذا النطاق يناسب احتياجكم الحالي، فالخطوة التالية ليست مشروع تحول كبير. الخطوة التالية تجربة تشغيلية مدفوعة ومحددة. نختار نطاقا واحدا، نشغل عملا حقيقيا داخل متقن، نقيس القيمة، ثم نقرر التوسع السنوي بناء على دليل.

## 13. إشارات خطر

نوقف أو نعيد تسعير أو نرفض إذا كان العميل:

- يتطلب تكاملات قبل إثبات القيمة الأساسية.
- لا يملك مالك تجربة.
- يريد تجربة مجانية بلا التزام استخدام حقيقي.
- يريد تخصيصا غير محدود.
- يريد نسخة منتج مخصصة.
- يقارن على السعر فقط بدون ألم تشغيلي.
- لا يستطيع توفير مستخدمين أو مواقع أو أصول أولية.
- يرفض قرار مراجعة أو تحويل بعد التجربة.

## 14. الخطوة الداخلية التالية

قبل استخدام العرض خارجيا:

1. اعتماد أو تعديل أسعار الإطلاق.
2. تأكيد القطاع الأول.
3. تجهيز نموذج التأهيل.
4. تجهيز قالب عرض تجاري.
5. تجهيز قوالب المتابعة.
