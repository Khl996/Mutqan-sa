# حزمة ما قبل عرض Pilot المدفوع

الحالة: مسودة تشغيلية داخلية قابلة للتنقيح  
التاريخ: 2026-05-02  
الغرض: تجهيز انتقال مهني من الديمو إلى اجتماع اكتشاف ثم عرض Pilot مدفوع محدود، بدون وعود مفتوحة أو توسيع غير مضبوط للنطاق.

## متى تستخدم هذه الحزمة؟

تستخدم هذه الحزمة بعد أن يشاهد العميل ديمو متقن ويبدي اهتماما جديا. الهدف ليس إرسال عرض مالي مباشرة، بل المرور بتسلسل منضبط:

1. اجتماع اكتشاف قصير لفهم النطاق والألم وصاحب القرار.
2. تقييم ملاءمة العميل لأول Pilot.
3. إن كان مناسبا، إرسال عرض Pilot محدود.
4. جمع بيانات أولية من العميل.
5. توقيع نطاق واضح قبل التشغيل.
6. تشغيل Pilot محدود، ثم تقرير أسبوعي وتقرير نهاية تجربة.

## قاعدة هذه المرحلة

لا نبيع "كل شيء". نبيع تجربة تشغيلية محدودة تثبت قيمة متقن في مسار واضح:

بلاغ أو أمر عمل، تعيين، تنفيذ، إغلاق أو اعتماد، ثم تقرير إداري.

أي تكاملات، تطبيق جوال أصلي، واتساب رسمي، دعم 24/7، تخصيصات كود كبيرة، أو تشغيل متعدد المواقع المعقد يجب ألا يدخل في أول Pilot إلا بقرار مستقل ونطاق وسعر منفصل.
