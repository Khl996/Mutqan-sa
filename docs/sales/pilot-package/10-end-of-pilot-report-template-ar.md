1. ماذا تم تشغيله؟

## 9. توصية الاشتراك السنوي

اختر توصية واحدة:

| التوصية | متى تستخدم؟ |
| --- | --- |
| الانتقال لاشتراك سنوي | القيمة ثبتت والاستخدام مقبول والنطاق التالي واضح |
| تمديد Pilot محدود | توجد قيمة لكن نحتاج بيانات أو استخدام أكثر قبل الاشتراك |

| عدم الاستمرار | لا يوجد استخدام كاف أو لا توجد قيمة مثبتة |
