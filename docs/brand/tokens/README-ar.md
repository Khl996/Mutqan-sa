# tokens — مقترحات Design Tokens لهوية متقن

هذا المجلد جزء من **Mutqan Brand Guidelines Document v1** وضمن برنامج **MBSU**.

## الغرض

تجميع مقترحات Design Tokens لهوية متقن بطريقة توثيقية فقط، بحيث يمكن لاحقًا تحويلها إلى Figma Styles أو CSS Variables أو Theme Tokens بعد اعتماد منفصل.

## مهم جدًا

هذه الملفات:

- لا تطبق ألوانًا في الكود.
- لا تغير CSS.
- لا تعدل الواجهة.
- لا تعتمد قيم HEX نهائية.
- لا تستبدل النظام الحالي.

هي فقط طبقة اقتراح وتنظيم.

## ما الذي يجب أن تغطيه tokens لاحقًا؟

- ألوان الهوية.
- ألوان الحالات التشغيلية.
- ألوان التقارير.
- الخطوط العربية والإنجليزية.
- أوزان الخطوط.
- المسافات.
- الحواف.
- الظلال.
- semantic tokens مثل:
  - `operating.stable`
  - `operating.warning`
  - `operating.risk`
  - `decision.brief`
  - `asset.health`
  - `workorder.status`

## العلاقة مع MBSU

الـ tokens هي ترجمة مستقبلية لنظام الهوية، وليست قرارًا بصريًا جديدًا. أي تطبيق فعلي يجب أن يعود إلى ملفات الهوية الرئيسية أولًا.
