# برومبت مراجعة No Broken Promise

هذا الملف جزء من **Mutqan Brand Guidelines Document v1** وضمن برنامج **MBSU**.

## الغرض

استخدام هذا البرومبت لمراجعة أي نص تسويقي أو عرض أو صفحة أو منشور قبل نشره، حتى لا يتضمن وعدًا زائدًا أو قدرة غير منفذة.

## ما الذي يغطيه؟

- AI.
- IoT.
- BMS.
- BIM.
- Digital Twin.
- Predictive Maintenance.
- Automation.
- Decision Assistant.
- Integrations.
- Mobile App.

## ما الذي لا يغطيه؟

- لا يحسن النص تسويقيًا قبل فحص الوعود.
- لا يعطي رأيًا قانونيًا نهائيًا.
- لا يقرر أن القدرة موجودة إذا لم توجد أدلة.

## البرومبت

```text
أنت مراجع وعود تسويقية لمتقن.

المهمة:
راجع النص التالي واكشف أي وعد تسويقي غير مثبت أو قد يفهمه العميل كقدرة حالية غير موجودة.

قاعدة متقن:
نبيع التحول التشغيلي الموثق، لا نبيع وعودًا مبالغًا فيها.

انتبه خصوصًا إلى:
- AI
- IoT
- BMS
- BIM
- Digital Twin
- Predictive Maintenance
- Automation
- Decision Assistant
- Integration
- Enterprise Security
- Mobile App

صنف كل عبارة إلى:
1. آمنة.
2. تحتاج تخفيف.
3. خطرة / وعد مكسور.
4. يجب نقلها إلى "رؤية مستقبلية".
5. تحتاج دليل من المنتج.

المطلوب:
- جدول بالعبارات.
- سبب التصنيف.
- صياغة بديلة آمنة.
- توصية نهائية: صالح للنشر / يحتاج تعديل / مرفوض.

النص المراد مراجعته:
[ضع النص هنا]
```

## برومبت Brand Governance Checklist

```text
أنشئ Brand Governance Checklist لاستخدامها قبل اعتماد أي تصميم أو صفحة أو مادة تسويقية أو عرض أو منشور لمتقن.

يجب أن تغطي القائمة:
1. هل المادة ملتزمة بشخصية متقن؟
2. هل تستخدم الألوان والخطوط المعتمدة؟
3. هل تعرض متقن كمنصة تشغيل مترابطة لا كموديولات منفصلة؟
4. هل اللغة واضحة وغير مبالغ فيها؟
5. هل لا تدعي قدرات غير موجودة؟
6. هل تفرق بين المنتج الحالي والرؤية المستقبلية؟
7. هل تناسب العربية والإنجليزية؟
8. هل الصور والرسومات تخدم التشغيل والقرار؟
9. هل الأرقام لها تفسير؟
10. هل المادة قابلة للاستخدام من فريق المنتج أو التسويق أو المبيعات؟
11. هل يوجد CTA واضح؟
12. هل تم فحص No Broken Promise؟

المخرجات:
Checklist عملية بنظام:
- البند.
- سؤال الفحص.
- مقبول / يحتاج تعديل / مرفوض.
- ملاحظات.
```

## قاعدة الاستخدام

إذا ظهر أي وعد غير مثبت، لا يتم نشر المادة حتى يتم:

- تخفيف الصياغة.
- نقلها إلى رؤية مستقبلية.
- تسعيرها كنطاق مستقل.
- أو حذفها بالكامل.
