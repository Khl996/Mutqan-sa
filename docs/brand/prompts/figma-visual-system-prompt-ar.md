# برومبت Figma / Visual System

هذا الملف جزء من **Mutqan Brand Guidelines Document v1** وضمن برنامج **MBSU**.

## الغرض

توجيه المصمم أو Figma لاحقًا لبناء اللغة البصرية لمتقن دون إعادة فتح قرارات الهوية.

## ما الذي يغطيه؟

- Visual Operating Graph.
- Asset Passport.
- Proof of Work.
- Decision Brief.
- Screenshot Story Frames.
- Motion concepts كاتجاه فقط.

## ما الذي لا يغطيه؟

- لا ينشئ ملف Figma هنا.
- لا يعيد تصميم الشعار.
- لا يختار ألوانًا جديدة.
- لا ينتج PDF أو فيديو.

## برومبت Visual Operating Graph

```text
أنت مصمم نظام بصري لمتقن.

السياق:
متقن منصة تشغيل وصيانة وإدارة أصول تبني الذاكرة التشغيلية الحية للمنشأة.
الشخصية: المستشار التشغيلي الهادئ.
القصة المركزية:
بلاغ ← موقع ← أصل ← فني ← مخزون ← تقرير ← قرار.

المطلوب:
صمم اتجاهًا بصريًا لـ Visual Operating Graph يوضح الترابط بين:
- البلاغ
- الموقع
- الأصل
- الفني
- المخزون
- التقرير
- القرار

القواعد:
- لا تصمم شعارًا جديدًا.
- لا تغيّر الألوان أو الخطوط.
- استخدم عقدًا وخطوط ربط وتايملاين وبطاقات هادئة.
- لا تستخدم رموز AI/IoT/BIM كقدرات حالية.

المخرجات:
- وصف المكونات.
- قواعد الخطوط والعقد.
- استخدام اللون.
- أمثلة استخدام في Landing Page وSales Deck وScreenshot Frames.
```

## برومبت Screenshot Story Frames

```text
حوّل لقطات شاشة المنتج إلى Story Frames تسويقية.

لا تعرض Screenshot خام.
كل لقطة يجب أن تحكي قيمة.

أنشئ 8 إطارات:
1. بلاغ جديد.
2. ربط البلاغ بالموقع.
3. ربطه بالأصل.
4. إسناده للفني.
5. التنفيذ وإضافة صور.
6. استخدام قطعة.
7. إثبات الإنجاز.
8. التقرير والقرار.

لكل إطار:
- عنوان قصير.
- نص داعم.
- ماذا نبرز في الصورة.
- السهم أو highlight المقترح.
- استخدام اللون.
- Insight أو CTA.
```

## برومبت Asset / Proof / Brief Components

```text
صمم مكونات بصرية أولية لـ:
- Asset Passport
- Proof of Work
- Decision Brief

القواعد:
- هادئة ومؤسسية.
- تعتمد Cairo/Inter.
- تستخدم ألوان الحالات بمعنى.
- تعرض التشغيل كذاكرة وقرار.
- لا تستخدم رسومات زخرفية أو Screenshots خام.
```
