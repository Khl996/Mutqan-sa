# docs/brand — مرجع هوية متقن

هذا المجلد هو المكان الرسمي داخل المشروع لتخزين وثائق هوية متقن العربية ضمن برنامج:

**Mutqan Brand System Upgrade Program — MBSU**

الغرض منه تحويل وثيقة **Mutqan Brand Guidelines Document v1** من نص واحد طويل إلى ملفات مرجعية قابلة للقراءة، التحديث، والاستخدام لاحقًا مع Codex والمطورين والمصممين وأدوات مثل Figma وCanva وNotion.

## ما هو هذا المجلد؟

`docs/brand` ليس مجلد تنفيذ تصميم، وليس مجلد كود. هو مرجع توثيقي يشرح:

- استراتيجية هوية متقن.
- نظام الرسائل والنبرة.
- اتجاه الشعار.
- نظام الألوان والخطوط.
- اللغة البصرية وVisual Operating Graph.
- مبادئ واجهة المنتج.
- مواد التسويق والمبيعات.
- الموشن والفيديو مستقبلًا.
- الحوكمة ومنع الوعود الزائدة.
- طريقة استخدام الوثيقة مع Codex وFigma وCanva ووكلاء AI.

## لمن يستخدم؟

- المؤسس والإدارة: كمرجع اعتماد للقرارات.
- المصمم: لفهم نظام الهوية قبل أي تصميم.
- مطور الواجهة وCodex: لمنع خلط الهوية بالكود أو تنفيذ خارج النطاق.
- التسويق والمبيعات: لضبط الرسائل والعروض والديمو.
- وكلاء AI لاحقًا: كسياق يحمي متقن من الوعود الزائدة والتشتت.

## القاعدة المركزية للهوية

متقن ليس مجرد CMMS ولا Dashboard عام ولا نظام تذاكر. متقن منصة تشغيل وصيانة وإدارة أصول تبني:

**الذاكرة التشغيلية الحية للمنشأة**

وشخصيته المعتمدة:

**المستشار التشغيلي الهادئ**

## القصة التشغيلية المركزية

كل قرار أو تصميم أو مادة مبيعات أو ديمو يجب أن يحافظ على هذه الرحلة:

**بلاغ ← موقع ← أصل ← فني ← مخزون ← تقرير ← قرار**

هذه ليست جملة تسويقية فقط. هي طريقة فهم المنتج، وطريقة شرح الديمو، وطريقة بناء التقارير، وطريقة عرض متقن للسوق.

## تحذير No Broken Promise

لا يجوز تقديم قدرات مثل AI أو IoT أو BMS أو BIM أو Digital Twin أو Predictive Maintenance كقدرات حالية مكتملة إلا إذا كانت منفذة فعليًا ومثبتة داخل المنتج.

الصياغة الآمنة:

> متقن يبني أساسًا تشغيليًا موثقًا يمكن أن يتطور لاحقًا نحو تكاملات وطبقات ذكاء أعمق حسب نطاق مستقل.

## عدم تعديل القرارات المعتمدة

لا يتم تغيير الاسم، أو فتح Rebranding كامل، أو تغيير الاتجاه اللوني، أو استبدال Cairo وInter، أو إعادة تعريف شخصية متقن دون مراجعة واعتماد صريح.

أي تحديث لهذه الملفات يجب أن يحافظ على:

- Mutqan Brand Guidelines Document v1.
- برنامج MBSU.
- شخصية المستشار التشغيلي الهادئ.
- القصة المركزية من البلاغ إلى القرار.
- قاعدة لا وعد بلا دليل.
