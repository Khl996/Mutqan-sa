# 04 — نظام ألوان متقن

هذا الملف جزء من **Mutqan Brand Guidelines Document v1** وضمن برنامج **MBSU**.

## الغرض من الملف

تثبيت فلسفة الألوان ودورها التشغيلي قبل تحويلها لاحقًا إلى Design Tokens أو تطبيقات تصميم.

## ما الذي يغطيه؟

- قرار الألوان.
- عائلات الألوان.
- استخدامات المنتج والتقارير والتسويق.
- ألوان الحالات التشغيلية.
- ما يجب تجنبه.

## ما الذي لا يغطيه؟

- لا يحدد HEX نهائية ملزمة.
- لا يطبق CSS.
- لا يغير الثيم.
- لا يصمم واجهة أو PDF.

## القرار التنفيذي

الاتجاه اللوني الحالي مناسب لمتقن كنواة، ويجب تطويره لا استبداله.

نحتفظ بالاتجاه:

**أزرق/فحمي مؤسسي غامق + تركوازي تشغيلي/تقني + خلفيات رمادية هادئة**

ونطوره من “ألوان متفرقة” إلى:

**نظام ألوان مؤسسي متعدد الطبقات يخدم الهوية، المنتج، التقارير، الحالات التشغيلية، التسويق، ومواد البيع.**

## فلسفة الألوان

ألوان متقن لا تصرخ. ألوان متقن ترشد.

اللون في متقن يجب أن يساعد المستخدم على معرفة:

- هل الوضع مستقر؟
- هل هناك خطر؟
- هل هذا مجرد رقم أم قرار؟
- أين أركز؟
- ما الذي تغيّر؟
- ما الذي يحتاج انتباهي؟

## عائلات الألوان

| العائلة | الدور |
| --- | --- |
| Operational Ink | فحمي/أزرق داكن للثقة والقيادة والعمق المؤسسي. |
| Signal Teal | تركواز مضبوط للربط والإشارة والتدفق ونقاط التفاعل. |
| Mutqan Neutral | رماديات للنصوص الثانوية والحدود والجداول والخلفيات. |
| Quiet Surface | أبيض مائل للرمادي أو الورقي لمساحات القراءة والتقارير. |
| Stable Green | استقرار، مكتمل، ضمن السيطرة. |
| Attention Amber | يحتاج متابعة، تحذير، ضغط تشغيلي. |
| Risk Red | خطر، توقف، SLA مكسور، أصل حرج. |
| Insight Blue/Teal | معلومة، Insight، توصية، إشارة تحليلية. |
| Paper/Stone Warmth | خلفيات تسويقية وPDF لإضافة دفء استشاري محدود. |

## قواعد المنتج

- الواجهة هادئة افتراضيًا وتصبح ملونة فقط عند وجود حالة أو قرار أو خطر.
- اللون الغامق يستخدم للهيكل والعناوين والثقة.
- التركواز يستخدم للأزرار الأساسية، selected states، الروابط المهمة، ومؤشرات الربط.
- الرمادي الفاتح هو خلفية التطبيق.
- الأبيض للأسطح والبطاقات والجداول.
- ألوان الحالات تستخدم في badges وalerts وrisk cards.

## ألوان الحالات التشغيلية

| الحالة | اللون | المعنى |
| --- | --- | --- |
| مستقر / مكتمل | أخضر هادئ | الوضع طبيعي أو ضمن السيطرة. |
| يحتاج متابعة | عنبري أو أزرق معلوماتي حسب السياق | يحتاج انتباهًا غير عاجل. |
| خطر / حرج | أحمر عميق محدود | تأثير تشغيلي فعلي أو وشيك. |
| معلومات / Insight | أزرق أو تركواز هادئ | ملاحظة أو توصية أو ربط. |
| غير نشط / ناقص بيانات | رمادي واضح | لا يمكن الحكم أو الحالة غير تشغيلية. |

## قواعد التقارير

- لا تستخدم الأحمر في الرسم إلا إذا كان المؤشر خطرًا فعلًا.
- لا تستخدم الأخضر لمجرد التجميل.
- استخدم الأزرق/الفحمي للمؤشرات الأساسية.
- استخدم التركواز للتحسن والربط.
- استخدم العنبر للتحذيرات.
- استخدم الرمادي للمقارنات الثانوية.

## قواعد التسويق والعروض

- الفحمي يبني الثقة.
- التركواز يشرح التدفق.
- الخلفيات الورقية أو الحجرية تضيف دفئًا استشاريًا.
- الأحمر يوضح المشكلة أو الخطر بحذر.
- لا نجعل كل التصميم داكنًا ولا كل التصميم أبيضًا باردًا.

## ما نتجنبه

- المبالغة في التركواز.
- الأسود القاسي.
- التدرجات الكثيرة.
- الأحمر كعنصر هوية.
- ألوان تقارير عشوائية.
- هوية تقنية فقط تشبه منتجات SaaS عامة.

## القاعدة الذهبية

> اللون الأساسي يبني الثقة. اللون الثانوي يوضح الحركة. ألوان الحالات تقود القرار.
