RTL / LTR Implementation
// RTL/LTR switching pattern
// globals.css
[dir="rtl"] {
  font-family: var(--font-arabic);
  direction: rtl;
}

// Sidebar — direction-aware
[dir="rtl"] .sidebar-item.active {
  border-left: none;
  border-right: 2px solid var(--teal);
}

// Drawer — slides from correct side
[dir="ltr"] .drawer {
  transform: translateX(100%);
}
[dir="rtl"] .drawer {
  transform: translateX(-100%);
}

// React context pattern
const dir = i18n.language === 'ar'
  ? 'rtl' : 'ltr';
document.documentElement
  .setAttribute('dir', dir);

Accessibility Notes
Color contrast: All text on backgrounds meets WCAG AA (4.5:1 for normal text, 3:1 for large). Deep Blue on white = 16.7:1. Turquoise on white = 2.9:1 — use only for large text/icons.
Focus states: All interactive elements use box-shadow: 0 0 0 3px rgba(0,178,169,0.2) on focus. Never remove outline — replace it with this branded version.
Status colors: Never use color alone to convey status. Always pair with a label, icon, or pattern. Critical = red + warning icon + text.
Arabic text: Cairo renders at 14px minimum. For body text, use 15–16px. Line-height for Arabic should be 1.7–1.8 (wider than English 1.6). Never mix Arabic and Latin in the same text node.
Motion: Always implement @media (prefers-reduced-motion: reduce) — collapse all animations to opacity fade only.
