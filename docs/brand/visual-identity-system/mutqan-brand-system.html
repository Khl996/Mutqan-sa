Motion Tokens
Timing & Easing
Token Value Use Case
--motion-fast120msHover, focus, toggle
--motion-normal200msButton press, state change
--motion-slow320msCard expand, drawer slide
--motion-page400msPage transition, modal
--ease-defaultcubic-bezier(0.2,0,0,1)All standard transitions
--ease-springcubic-bezier(0.34,1.56,0.64,1)Success states, confirmations
--ease-precisecubic-bezier(0.25,0.46,0.45,0.94)Data / chart animations
Motion Rules for Mutqan
Calm over flashy
No bounce, pop, or spring on data changes. Reserve spring easing for user confirmations only (e.g. work order marked complete).
Status pulse
Critical/active states use a slow 2.5s opacity pulse (0.6→1.0→0.6). Not a flash — a breath. Signals live operational awareness.
RTL motion direction
In RTL mode, drawers slide in from the right. Page transitions slide right→left for forward navigation, left→right for back.
Reduced motion
Always respect prefers-reduced-motion. Fade to opacity:0/1 only. No slide, no scale.
Timeline trace animation
Timeline lines draw from left (LTR) or right (RTL) using SVG stroke-dashoffset at --motion-slow with --ease-precise.

4 · الاستخدام الصحيح والخاطئ — Do's & Don'ts
✓ الصحيح
✓استخدم الألوان من النظام المعتمد فقط
✓استخدم Cairo للعربية وInter للإنجليزية دائماً
✓حافظ على الـ clear space حول الشعار
✓استخدم أيقونات من عائلة واحدة بـ 1.75px stroke
✓ضع لقطات المنتج داخل إطار نظيف مع highlight
✓استخدم خلفيات هادئة (#F8F9FA أو #0F1B2B)
✓ابقَ ضمن الطابع المؤسسي الهادئ في كل أصل
✗ الخاطئ
✗لا تستخدم ألواناً خارج نظام الألوان المعتمد
✗لا تستخدم gradients صاخبة أو ملوّنة
✗لا تمدّ الشعار أو تشوّهه أو تغيّر ألوانه
✗لا تخلط أيقونات من عائلات تصميم مختلفة
✗لا تضع screenshots خام بدون إطار
✗لا تزدحم التصميم بالنصوص أو العناصر
