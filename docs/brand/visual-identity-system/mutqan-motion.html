G1 · Motion Principles
Mutqan Motion Design Language
Calm, precise, enterprise-grade. Motion explains operational flow — it does not decorate it.
Calm over Fast
Transitions are unhurried. Duration respects the user's cognitive context — fast for micro-interactions, slower for page-level moves.
--motion-normal: 200ms
Purposeful Movement
Every animation communicates something: status changing, data loading, a decision being recorded. No decorative motion.
--ease-default: cubic-bezier(0.2,0,0,1)
Layered Traces
Timeline lines draw progressively. Cards appear in staggered sequence. The visual rhythm mirrors the operational flow: step by step.
stagger-delay: 60ms per item
RTL-Aware Direction
All directional animations mirror for Arabic/RTL context. Drawers enter from the right. Slides advance right→left.
transform: scaleX(-1) for RTL
Status Pulse
Active
Slow opacity pulse 2.5s. Used for live status indicators. Not a flash — a breath.
Timeline Trace Draw
SVG stroke-dashoffset draw. Used for logo intro, timeline reveals, operational flow animations.

G4 · Export Guidance
Motion Export Implementation Notes
Lottie / AE
Export logo animation, timeline traces, and status pulse as Lottie JSON via AE + Bodymovin plugin. Frame rate: 60fps for smooth SVG draws.
SVG / CSS
All timeline animations use SVG stroke-dashoffset with CSS animation. Cards use transform + opacity via CSS transitions with var(--ease-default).
path {
  stroke-dasharray: 120;
  stroke-dashoffset: 120;
  animation: draw 0.8s
    var(--ease-precise)
    forwards;
}
GSAP
Use GSAP for complex sequences: logo intro (DrawSVG plugin), staggered card reveals (gsap.from with stagger:0.06), and count-up KPI numbers (gsap.to with counter object).
Canva Video
Use Canva's built-in animation options for social versions. Apply "fade" for text reveals, "pan" for slide transitions. Export at 1080p MP4 for LinkedIn.
